## 📖 项目简介
SkyEye云 是面向**智能制造行业**的一站式SaaS化零代码全链路管理平台，一套底座覆盖企业数字化全场景：
内置CRM客户管理、ERP进销存、MES生产制造、WMS仓储、OA行政办公、EHR人事薪资、项目管理、商城、财务、售后工单、工作流引擎、智能报表等**上百种业务模块**。
依托自研零代码设计器，无需编写原生CRUD代码，拖拽式快速搭建业务表单、流程、打印模板，支持PC端+移动端（小程序/H5/App）多端同源发布，是中小企业智能制造数字化落地一站式解决方案。

> 项目归属Dromara开源社区，开源主干持续迭代，同时提供商用完整版源码会员服务。

- `零代码能力`: 本 AI 低代码平台以低代码 + 零代码双模模式为核心，在统一平台底座之上，为开发者提供低代码开发能力，同时为业务人员提供零代码可视化搭建能力，打通技术开发与业务自主搭建的能力壁垒。

- `AI自动化测试平台`：自动化测试平台是自主研发的研发协同与质量平台。围绕需求、版本、模块和缺陷打通全流程，支持交互式需求拆分、一句话提 Bug、截图识图提单，以及前后端测试任务协同，实现“一次录入，多角色协同”。界面按业务场景组织，支持版本联动、默认环境、非问题判定，轻松把日常研发管理做成可追溯、可度量的数字化工作台。

- `AI智能进销存`：SkyEye ERP 是自主研发的进销存与供应链协同平台。围绕物料、采购、销售、库存、财务和设备运维打通业财一体，支持智能开单、库存预警解读、采购补货建议、对账单摘要，以及设备故障截图报修，实现“一句话录入，全链路可追溯”。单据按业务场景流转，支持多仓库、多组织协同，轻松把日常进销存做成可预警、可分析的数字化经营台。

- `AI智能办公`：SkyEye OA 是自主研发的协同办公平台。围绕审批、日程、考勤、知识库和内部论坛组织日常办公，支持一句话起草请假/公文、会议纪要自动整理、知识库问答、待办智能摘要，实现“一次提问，自动成文”。流程像聊天一样发起，支持多端待办、知识沉淀和制度检索，轻松把繁琐行政事务做成可检索、可复用的智能办公助手。

- `AI智能制造`：SkyEye MES 是自主研发的生产执行与车间协同平台。围绕生产计划、工艺路线、工单报工、领退料和质检闭环管理现场，支持智能排产建议、异常原因分析、质检截图判定、工序作业指导，实现“一次报工，全程可视”。现场按工序流转，支持多车间、多产线协同，轻松把生产过程做成可调度、可追溯的智能工厂底座。

- `AI智能审批`：SkyEye 工作流是贯穿各业务系统的统一审批引擎。围绕请假、采购、合同、生产变更等单据自动流转，支持一句话发起流程、审批意见摘要、风险点提示和智能驳回建议，实现“一次描述，自动走流程”。表单与流程解耦，支持多组织、多角色会签，轻松把跨系统审批做成可解释、可审计的智能决策通道。

- `AI智能商城`：SkyEye 商城是面向门店与线上订单的交易平台。围绕商品、订单、售后和门店运营管理零售链路，支持商品文案生成、售后工单摘要、评价情感分析和补货建议，实现“一次上架，多端售卖”。订单按门店与渠道汇总，支持售后协同和经营看板，轻松把零售业务做成可运营、可增长的数字化店铺。

## ✨ 核心优势
- 🧩 **全场景一体化**：一套系统打通产销存、生产、人事、财务、售后全业务，告别多系统割裂
- ⚡ **低代码零开发**：内置表单/布局/工作流/编码/打印五大可视化设计器，零基础快速定制业务
- 📱 **一次开发多端适配**：Vue3+PC + uni-app移动端，一套代码同步发布APP/小程序/H5
- 🏢 **SaaS多租户架构**：原生支持多企业租户隔离、精细化权限管控，适配集团化部署
- 🛠️ **企业友好授权**：商用会员拿到源码后，自研二开产品可去除原项目Copyright与作者标识

## 🧰 技术架构与环境依赖
### 后端技术栈（Spring Cloud Alibaba微服务）
| 技术组件 | 版本 | 用途 |
| ---- | ---- | ---- |
| Spring Cloud Alibaba | 2.1.0.RELEASE | 微服务基座 |
| Nacos | 2.3.0 | 注册中心+配置中心 |
| RocketMQ | 4.9.2 | 分布式消息队列 |
| Sentinel | 2.1.0.RELEASE | 流量熔断、服务容错 |
| XXL-Job | 2.3.0 | 分布式定时任务 |
| Activiti | 6.8.0 | 工作流引擎 |
| Mybatis-Plus | 3.5.7 | ORM框架 |
| Druid | 1.2.23 | 数据库连接池 |
| Redis | 5.0+/6.x | 缓存中间件 |
| MySQL | 5.7+/8.0 | 业务数据库 |
| Hutool/Lombok | 常用稳定版 | 工具类与代码简化 |

### 前端技术栈
- PC端：Vue3 + Vite5 + Ant Design Vue4
- 移动端：uni-app(Vue3)，一套代码编译安卓/IOS/小程序/H5

### 基础运行环境
- JDK 1.8
- MySQL(默认端口3308)、Redis(6379)、Nacos(8848)、RocketMQ(9876)
