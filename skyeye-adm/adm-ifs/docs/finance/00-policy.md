# 业财一体化政策冻结（Phase 0）

> 状态：已冻结，作为引擎与模板配置的唯一业务口径。变更需财务 + 研发评审。

## 1. 账套与期间

| 项 | 政策 |
|----|------|
| 本位币 | CNY |
| 会计期间 | 自然月；年度 1–12 |
| 期间状态 | OPEN → BIZ_CLOSED → FIN_CLOSED |
| 关账规则 | FIN_CLOSED 后禁止业务改单与凭证过账；冲销走红字凭证 |

## 2. 成本域与计价

| 项 | 政策 |
|----|------|
| 默认成本域 | 与账套 1:1（单组织可先一个成本域） |
| 计价方法 | 移动加权平均（MOVING_AVG）；物料档案可覆盖 |
| 暂估 | 采购入库未到票贷「应付暂估」；到票冲暂估 |

## 3. 收入确认

| 场景 | 时点 |
|------|------|
| 一般销售 | 销售出库审核生效 |
| 退货 | 销售退货入库审核生效，红字冲销收入与成本 |

## 4. 辅助核算

按科目启用：客户、供应商、物料、部门、项目、仓库。应收/应付强制往来单位；存货类强制物料。

## 5. 凭证编号

`记-{YYYYMM}-{流水4位}`，按账套+期间独立流水。

## 6. 幂等

`idempotencyKey = eventType + sourceType + sourceId + version`，重复受理直接返回已有凭证。
